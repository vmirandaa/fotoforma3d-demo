# FORMA · demo

Copia de demostración del sitio de figuras 3D de mascotas, publicada en GitHub Pages para mostrar el avance.

**No tiene servidor:** `js/demo-api.js` simula las respuestas en el navegador.

- **Creador (`crear.html`)**: la vista previa tarda unos segundos y siempre muestra el modelo de muestra. Las reservas quedan guardadas solo en tu navegador.
- **Mi pedido (`ingresar.html`)**: prueba con `F-C04E8A19` y `valentina@ejemplo.cl`, o con una reserva hecha en el creador.
- **Panel (`ingresar.html#admin`)**: entra con cualquier usuario y clave (por ejemplo `demo` / `demo`). Trae 4 reservas de ejemplo; los cambios de estado se guardan en tu navegador.

No se envían correos ni se usa el servicio de generación 3D.
